# Support / 支持

## English

For usage questions, start with:

1. [README.md](README.md)
2. [references/INSTALL.md](references/INSTALL.md)
3. [references/TROUBLESHOOTING.md](references/TROUBLESHOOTING.md)
4. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)

When opening an issue, include the operating system, Python version, command, sanitized log excerpt, input format, and the stage that failed. Remove usernames, absolute paths, tokens, private model data, and host-only prompt contents first.

## 中文

使用问题请先阅读：

1. [README.zh-CN.md](README.zh-CN.md)
2. [references/INSTALL.md](references/INSTALL.md)
3. [references/TROUBLESHOOTING.md](references/TROUBLESHOOTING.md)
4. [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)

提交 Issue 时请说明操作系统、Python 版本、执行命令、脱敏后的日志片段、输入格式和失败阶段。提交前务必删除用户名、绝对路径、令牌、私有模型数据和宿主私有提示词。
