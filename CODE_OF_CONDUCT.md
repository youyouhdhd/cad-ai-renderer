# Code of Conduct / 行为准则

## English

We want a technically rigorous and welcoming project. Contributors must be respectful, assume good faith, discuss evidence rather than people, and keep reviews focused on the work. Harassment, discrimination, threats, doxxing, sexualized conduct, and deliberate disclosure of private information are not acceptable.

Maintainers may edit, reject, or remove contributions that violate this standard. To report a conduct concern, open a private GitHub report when available; otherwise open an issue with only the minimum non-sensitive context and ask a maintainer to move the discussion to a private channel.

## 中文

我们希望项目既严谨又友好。贡献者应保持尊重、善意理解，以证据而非针对个人进行讨论，并让 Review 聚焦于代码和文档本身。骚扰、歧视、威胁、人肉、性化言行，以及故意披露私人信息均不可接受。

维护者可以编辑、拒绝或移除违反本准则的贡献。行为问题优先使用 GitHub 的私密报告功能；若不可用，请只在 Issue 中提供最少且不敏感的背景，并请求维护者转入私下渠道。
